# FF 스타일 텍스트 RPG (확장용 뼈대)

## 무기 7계열

마을 무기점과 분해·합성 공방에서 7계열을 선택할 수 있고 몬스터·탑 보상의 무작위 무기에도 적용됩니다. 직업마다 지정된 계열만 착용할 수 있습니다.

| 계열 | 상점 무기 | 기본 능력치 | 가격 |
|---|---|---|---|
| 검 | 철검 | 공격 +5 | 50G |
| 지팡이 | 참나무 지팡이 | 공격 +2, 최대 MP +8 | 55G |
| 단검 | 철제 단검 | 공격 +3, 속도 +2, 회피 +3% | 55G |
| 창 | 수비대 장창 | 공격 +4, 방어 +2 | 55G |
| 활 | 사냥꾼 장궁 | 공격 +4, 치명타 +8% | 60G |
| 도끼 | 전투 도끼 | 공격 +8, 속도 -2 | 60G |
| 권갑 | 철제 권갑 | 공격 +5, 속도 +1 | 58G |

계열 특성은 기존 전투의 공격·턴 순서·치명타·회피·최대 MP 계산에 반영됩니다. 각 직업은 지정된 무기 계열만 착용할 수 있습니다. 모든 무기는 강화당 공격 +2이며, 계열 특성과 부가 능력치는 유지됩니다. 동일 장비 또는 성운석으로 +5까지 강화할 수 있습니다. 같은 계열이라는 이유만으로 다른 이름의 무기를 재료로 쓰지는 않습니다.

기존 저장은 알려진 무기 이름에서 계열을 복원하며 원래 능력치는 보존합니다. 무작위 장비의 무기/방어구/장신구 추첨 비율은 유지하고, 무기 내에서 7계열을 추첨합니다.

## 실행 방법

### 콘솔판

```
python3 main.py
```

### 웹 완성판

```bash
python3 web_app.py --open
```

브라우저가 자동으로 열리지 않으면 `http://127.0.0.1:8000`에 접속하세요. 같은 와이파이의 스마트폰에서 시험하려면 방화벽 설정을 확인한 뒤 `python3 web_app.py --host 0.0.0.0`으로 실행하고, 컴퓨터의 내부 IP 주소와 포트 `8000`으로 접속합니다.

파이썬 3.8 이상이면 별도 라이브러리 설치 없이 바로 실행됩니다.

### Docker 실행

```bash
docker compose up --build
```

`http://127.0.0.1:8000`으로 접속합니다. `compose.yaml`은 저장 슬롯을 `game-saves` 볼륨에 보존하고 브라우저별 세션 분리를 활성화합니다. 서버 환경에서는 `HOST`, `PORT`, `RPG_SAVE_DIR`, `RPG_MULTI_SESSION` 환경 변수로 수신 주소·포트·저장 폴더·다중 세션 사용 여부를 지정할 수 있습니다.

### HTTPS 호스팅 배포

`Dockerfile`과 `render.yaml`이 포함되어 있어 Git 저장소에 올린 뒤 Render Blueprint 등 Docker를 지원하는 호스팅 서비스에 연결할 수 있습니다. 호스팅 서비스가 외부 HTTPS를 처리하고 컨테이너는 `PORT` 환경 변수로 지정된 포트에서 실행됩니다. 상태 확인 경로는 `/api/health`입니다.

무료 인스턴스의 로컬 파일은 재배포·재시작 과정에서 초기화될 수 있습니다. 웹판은 저장 슬롯을 브라우저에도 함께 백업하고 서버 슬롯이 사라지면 다음 접속 때 자동 복원합니다. 다만 브라우저 사이트 데이터를 삭제하거나 다른 기기를 사용하면 이 백업에 접근할 수 없으므로, 여러 기기 공유나 장기 운영에는 유료 영구 디스크 또는 외부 저장소가 필요합니다. Docker·Render 설정은 `RPG_MULTI_SESSION=1`을 적용하여 브라우저마다 게임 상태와 저장 슬롯을 분리합니다. 일반 `python3 web_app.py` 실행은 콘솔판과 동일한 로컬 저장 슬롯을 공유하는 단일 세션 모드입니다.

## 파일 구조
- `models.py` — 캐릭터, 스킬, 아이템, 장비, 상태이상, 파티의 기본 뼈대(클래스). 게임 규칙(공격력 계산, 레벨업 공식 등)을 바꾸고 싶을 때 여기를 수정하세요.
- `data.py` — 전투 콘텐츠(직업, 스킬, 적, 아이템, 장비).
- `combat.py` — 턴제 전투 진행 로직 (속도 기반 턴 순서, 턴 시작 시 상태이상 처리, 공격/스킬/아이템/방어/적 정보/도주 선택, 승리 시 경험치·골드 지급).
- `map.py` — 맵 이동 엔진 (`Location`, `GameMap`, `explore()`). 이동/랜덤 인카운터/보스전/대화 재생/장비 관리/상점/저장을 하나의 선택지 메뉴로 묶어 처리하는 범용 로직.
- `world.py` — 실제 맵 데이터(장소, 장소 간 연결, 어디서 어떤 몬스터가 나오는지, 어떤 대화·상점이 연결되는지). **새 지역/던전을 추가할 때 가장 자주 건드리게 될 파일**입니다.
- `story.py` — 대사+선택지 스토리 이벤트 엔진 (`DialogueNode`, `Dialogue`). 선택 결과는 `flags` dict에 저장되어 이후 다른 대화/엔딩에서 참조할 수 있습니다.
- `quests.py` — 퀘스트 정의, 수락·진행·완료·보상, 퀘스트 일지와 마을 의뢰 게시판.
- `dialogues.py` — 실제 대사와 분기 내용. **새 스토리 이벤트를 추가할 때 가장 자주 건드리게 될 파일**입니다.
- `equipment.py` — 파티원의 장비(무기/방어구/장신구)를 착용/해제하는 메뉴 UI.
- `shop.py` — 골드로 아이템/장비를 사고파는 상점 UI.
- `crafting.py` — 미착용 장비 분해와 계열·등급 지정 무기 합성 규칙 및 콘솔 공방 UI.
- `save.py` — 안전한 저장/불러오기와 상세 슬롯 요약 (JSON 파일, `saves/slot1.json`~`slot3.json`).
- `input_utils.py` — 모든 콘솔 메뉴에서 0·음수·범위 밖 입력을 막는 공통 입력 검증.
- `equipment_simulator.py` — 무작위 장비의 등급·옵션·가격 분포를 반복 분석하고 보고서를 생성.
- `web_app.py` — 표준 라이브러리만 사용하는 로컬 웹 서버와 게임 상태 API. 월드맵·대화·전투·상점·장비·퀘스트·저장을 브라우저 UI에 연결.
- `web_ui/` — 스마트폰과 데스크톱에 대응하는 전체 웹 플레이 화면과 PWA 자원(`manifest.webmanifest`, `sw.js`, 앱 아이콘 포함).
- `Dockerfile`, `compose.yaml`, `render.yaml` — 로컬 컨테이너 실행과 HTTPS 호스팅 배포 구성.
- `test_web_app.py` — 웹 파티 편성, 이동, 대화, 전투, 상점, 장비, 퀘스트, 저장·불러오기와 PWA 자원을 검사.
- `main.py` — 게임 실행 흐름. 시작 시 저장 파일이 있으면 이어하기/새 게임을 물어보고, 파티 생성 → `world.build_world()`로 맵 로드 → `explore()`로 탐험 시작.

## 지금 구현된 것
- 전사/마법사/힐러/도적/궁수/소환술사 6직업. 게임 시작 시 파티원 3명(레온/리제/셀린)의 직업을 각각 직접 선택함
  - 도적은 20% 확률로 1.5배 치명타를 가하고 직접 공격을 15% 확률로 회피함. 중독 등 지속 피해는 회피할 수 없음
- 기본 공격 / 스킬(공격형·회복형·도둑형·버프형·디버프형) / 전체공격(광역) 스킬 / 아이템 / 방어
  - **무기 연계 공격**: 검·창·단검·활·도끼·권갑을 착용한 서로 다른 파티원이 같은 턴에 같은 적을 단일 대상 기본 공격 또는 무속성 공격 스킬로 이어 치면 두 번째 타격부터 추가 위력을 얻음. 검·단검·활·권갑은 2/4, 창·도끼는 3/6 증가하며 세 번째 타격까지 누적됨. 빗나감·비공격 행동·새 턴에 연계가 초기화됨. 웹 전투에는 다음 연계 대상과 보너스가 표시됨
  - 3타 연계는 마지막 공격자의 무기에 따라 마무리 효과가 달라짐: 검은 방어 약화, 단검은 중독, 창은 강한 방어 약화, 활은 속도 약화, 도끼는 공격 약화, 권갑은 1턴 경직을 부여함. 효과는 공격이 적중하고 대상이 생존한 경우에만 적용됨
  - 방어하면 다음 행동 직전까지 받는 직접 공격 피해가 절반으로 감소함
- **전투 편의 기능**: 매 턴 시작 시 파티와 적 전체의 HP·MP·상태 효과와 남은 지속시간을 표시함
  - `적 정보`에서는 살아 있는 적의 현재 HP, 약점, 저항, 상태 효과를 확인할 수 있으며 행동을 소비하지 않음
  - 공격 대상·스킬·아이템 선택 화면에서 `이전 메뉴`로 돌아갈 수 있고, 취소한 행동은 MP나 아이템을 소비하지 않음
  - 일반 전투에서는 도주할 수 있음. 기본 성공률은 60%이고 양측 평균 속도 차이에 따라 5%p씩 변하며 최소 25%·최대 90%로 제한됨
  - 도주 성공 시 경험치·골드·드랍 보상은 없으며, 실패하면 해당 캐릭터의 행동을 소비함. 미니보스·보스·최종보스 전투에서는 도주할 수 없음
- 속도 기반 턴 순서 (간단한 ATB 느낌)
- 승리 시 경험치·골드 획득 및 레벨업
- 슬라임·야생 늑대·박쥐 무리(숲 입구), 고블린·독거미·오크 전사·숲의 정령(깊은 숲), 그림자 추적자·저주받은 원혼(그림자 골짜기), 스켈레톤 광부·유령 광부(폐광), 다크 나이트·봉인된 마왕(메인 스토리 보스)·탄광 드레이크·동굴 골렘·탑의 수호자(사이드 보스/미니보스) 등 스탯 특성이 다른 몬스터 15종+
  - 빠르지만 약한 타입(박쥐 무리), 탱커형(오크 전사), 자가 회복형(숲의 정령), 상태이상 부여형(독거미·스켈레톤 광부), 속도 저주형(유령 광부) 등으로 역할이 나뉘어 있음
  - 깊은 숲/폐광/도전의 탑에서는 2마리가 함께 나오는 조우도 있음
- **맵 이동**: 장소 간 이동, 장소별 랜덤 인카운터 확률, 보스방/미니보스방, 보물(1회성 아이템/장비 획득), 엔딩 지점, 지도 보기(가본 곳만 표시)
  - 웹 플레이에서는 마왕 처치 후 `심연 변이 던전`이 열림. 4개 층의 적 조합과 광폭화·철벽·정예 군단 변이가 매번 바뀌며, 층별 임시 골드와 장비 조각(2·4·6·8개)을 안전 귀환으로 확정하거나 전멸 위험을 감수하고 다음 층에 도전할 수 있음. 완주 시 장비 조각 15개를 추가 지급하며 반복 완주마다 2개씩 증가해 최대 25개가 됨
  - 웹 지도는 `전체 맵`과 `지역 맵`으로 분리됨. 전체 맵은 8개 권역의 발견 수·해금 상태를, 지역 맵은 현재 권역 안의 방문 장소·인접 미발견 장소·확인된 연결 경로를 표시함
  - 전투와 대화를 마친 탐험 상태에서는 모든 지역에서 시작 마을로 즉시 귀환할 수 있음. 기존에 마을 직행 경로가 있는 장소는 해당 경로를 그대로 사용함
  - 대화 선택으로 저장되는 story flag에 따라 길이 열리거나 잠김. 오프닝에서 장로의 부탁을 수락하면 시작 마을의 비밀 무기고가 열리고 전용 장신구 `장로의 수호 인장`을 획득할 수 있음
  - 보스는 최초 처치 후 같은 보스방에서 언제든 다시 도전할 수 있음. 재전투의 경험치·골드·일반 드롭은 지급되지만 퀘스트 보상과 보스 전용 보물은 최초 1회만 지급됨
  - 현재 맵(총 31개 장소): 시작 마을(상점가·조건부 비밀 무기고) → 숲 입구 → { 깊은 숲 → 그림자 골짜기 → 버려진 폐허(보스) → 봉인의 문 → 봉인의 방(진짜 최종보스+최고 보상) → 엔딩 } / { 깊은 숲 → 안개 습지 → 침수된 나무길 → 잊힌 사당(안개의 여왕+안개의 망토) → 달빛 샘 → 가라앉은 기록실 → 메아리의 석실(미니보스+기록실의 등불) } / { 동굴 → 동굴 보물방(미니보스+보물) / 동굴 비밀 금고(열쇠로 개방) } / { 폐광 입구 → 폐광 깊은 곳(열쇠 획득) → 폐광 가장 깊은 곳(보스+보물) }으로 갈라지는 구조, 마을에서 별도로 { 도전의 탑 1~3층 → 탑 정상(최강 보스+최고급 보물) }도 갈 수 있음. 마왕 처치 후에는 { 북쪽 관측소 → 유성 낙하지 → 별의 균열 }, 균열 봉쇄 후에는 { 별빛 회랑 → 부서진 천문성소 → 공허의 왕좌 }가 열림
  - 동굴의 "동굴 골렘" → 미스릴 대거 / 폐광의 "탄광 드레이크" → 드레이크 비늘 갑옷 / 탑 정상의 "탑의 수호자" → 전설의 갑옷 / 메인 스토리 최종보스 "봉인된 마왕" → 봉인 해방의 검 (모두 상점에서 파는 것보다 강력한 전용 보상)
  - 봉인된 마왕 처치 시 승리 보상과 봉인 해방의 검을 받은 뒤 선택에 따른 엔딩 대사를 보고 시작 마을로 자동 귀환함. 봉인의 방에 다시 찾아가면 보스 재도전이 가능하며 엔딩 대사·보물은 중복 지급되지 않음
  - 후일담 챕터 `검은 별의 신호`: 마왕을 최초 처치한 뒤 시작 마을의 북쪽 관측소가 열림. 관측소에서 장로에게 신호를 알릴지 선택하고 유성 낙하지의 별의 균열에서 `검은 별의 잔재`를 쓰러뜨리면 전용 `별의 수호 부적`과 선택별 후일담을 한 번 얻음. 이전 저장의 마왕 처치 기록도 개방 조건으로 복원됨
  - 다음 미션 챕터 `별 너머의 문`: 별의 균열을 닫은 뒤 별빛 항로가 열림. 귀환 봉화를 밝힐지 선택하고 부서진 천문성소를 지나 `공허의 관측자`를 쓰러뜨리면 전설 창 `성좌의 창`과 선택별 보너스를 얻음
- **스토리 대화 & 분기**: 장소 진입 시 1회성 대화 재생, 선택지에 따라 `flags`에 결과 저장, 이후 다른 대화(엔딩 등)에서 그 결과를 참조해 대사가 달라짐
  - 현재 예시: 마을 노인의 부탁을 수락/거절(`promised_elder`) + 다크 나이트를 처치한 뒤 발견하는 봉인의 힘을 받아들일지 거부할지(`embraced_power`) — 두 선택의 조합으로 엔딩 대사가 4갈래로 갈림. 봉인의 힘을 받아들이면 최종전 직전에 파티 전체의 최대 HP +6, 공격력 +2, 방어력 +1이 실제 적용됨
  - 세아를 구하면 달빛 샘에서 숨은 수로가 열림. 기록실에서 봉인의 균열을 장로에게 알릴지 선택하고 메아리를 잠재우면, 기존 4갈래 엔딩에 그 선택의 후일담이 덧붙음
- **퀘스트 시스템**: `미수락 → 진행 중 → 보상 수령 가능 → 완료` 상태를 관리하며 모든 지역에서 퀘스트 일지를 확인할 수 있음
  - 마을 의뢰 게시판에서 의뢰를 수락하고 목표 달성 후 골드·아이템 보상을 수령함
  - 메인 퀘스트 `폐허의 어둠`: 오프닝에서 노인의 부탁을 수락하면 자동 등록되며 다크 나이트 처치 후 포션 2개와 50G 지급
  - 사이드 퀘스트 `광부들의 안식`: 탄광 드레이크 처치 후 에테르·해독제와 45G 지급
  - 사이드 퀘스트 `안개 속 약초꾼`: 안개의 여왕을 처치하고 달빛 샘의 약초꾼 세아를 구출하면 해독제 2개·에테르·60G 지급. 세아를 마을까지 호위하면 20G 추가 지급
  - 사이드 퀘스트 `봉인의 잔향`: 기록실에서 단서를 발견하면 자동 수락. 석실의 봉인의 메아리를 처치하면 달빛 영약·65G 지급, 기록을 장로에게 전하기로 했다면 25G 추가 지급. 전용 장신구는 보스 첫 처치 후 한 번만 획득
  - 메인 퀘스트 `검은 별의 신호`: 관측소에서 신호를 확인하면 자동 수락. 별의 균열을 닫으면 달빛 영약·90G 지급, 장로에게 먼저 알렸다면 20G 추가 지급
  - 메인 퀘스트 `별 너머의 문`: 별빛 회랑에 진입하면 자동 수락. 공허의 관측자를 처치하면 달빛 영약 2개·130G 지급, 귀환 봉화를 밝혔다면 30G 추가 지급
  - 달빛 샘의 NPC 대화 선택은 `found_herbalist`·`escorted_herbalist` 플래그로 저장되어 실제 퀘스트 보상에 반영됨
  - 목표를 먼저 달성한 뒤 의뢰를 수락해도 즉시 보상 수령 가능 상태가 되며, 완료 보상은 한 번만 지급됨
- **직업 성장 시스템**: 모든 직업이 2·3·4레벨에 신규 스킬을 배우거나 대표 스킬을 강화함
- **직업·2차 전직**: 기본 직업은 전사·마법사·힐러·도적·궁수·소환술사·기사·무도가·창술가·마도사 10종이며, Lv.5 이상이면 시작 마을 전직 교관에서 직업별 3개 계열 중 하나를 선택할 수 있음. 창술가는 창성·용창기병·파수창병, 마도사는 비전술사·주술사·마검사로 전직 가능. 기존 기술을 유지하고 계열 전용 기술·능력치 보너스를 얻으며 파티원당 한 번만 전직 가능. 기존 저장도 불러올 수 있음
  - 2레벨: 직업의 역할을 넓히는 기술 습득
  - 3레벨: 대표 스킬이 강화판으로 교체됨
  - 4레벨: 광역기 또는 고급 보조기 습득
  - 레벨업 화면에서 새 스킬과 강화 내용을 안내하며, 기존 저장 파일의 고레벨 캐릭터도 불러올 때 현재 레벨에 맞게 자동 보정됨
- **장비 시스템**: 무기/방어구/장신구 3슬롯. 장착 시 공격력/방어력/속도/최대HP/최대MP에 보너스가 붙음(기본 스탯은 그대로 두고 "효과가 적용된 실제 스탯"을 따로 계산). 탐험 메뉴의 "장비 관리"에서 파티원별로 착용/교체 가능
  - 직업별 사용 무기: 전사(검·도끼), 마법사/힐러/소환술사(지팡이), 도적(단검), 궁수(활), 기사(검·창), 무도가(권갑), 창술가(창), 마도사(지팡이·검)
  - 호환되지 않는 무기는 장비 화면에서 비활성화되며 서버에서도 장착을 거부한다. 구버전 저장에 이미 장착된 무기는 불러오기를 위해 그대로 유지됨
  - 장비 등급은 일반·고급·희귀·영웅·전설 다섯 단계이며 장비명 앞에 등급이 표시됨. 랜덤 장비는 등급별로 0~4개의 서로 다른 옵션이 붙고 영웅·전설 등급은 가격과 강화 비용도 더 높음
  - 일반 몬스터는 5% 확률로 자신의 레벨에 맞는 무작위 장비를 떨어뜨림
  - 고급 이상 무작위 장비에는 등급에 따라 예리함·견고함·활력·신속·집중 옵션이 1~4개 붙음
  - 보스 전용 장비는 치명타율·회피율·받는 피해 감소 등의 고유 효과를 가짐
  - 무작위 장비의 능력치와 옵션은 저장 파일에 그대로 기록되어 불러온 뒤에도 유지됨
- **대장간 강화**: 시작 마을에서 미착용 장비를 +1~+5까지 확정 강화할 수 있음. 같은 이름의 장비 1개와 단계·등급별 골드를 재료로 사용하며 실패나 장비 파괴는 없음
  - 무기는 단계당 공격력 +2, 방어구는 방어력 +1·최대 HP +3, 장신구는 속도 +1·최대 MP +2가 상승함
  - 강화 단계와 상승 능력치는 저장 파일에 기록되며 웹·콘솔에서 동일하게 유지됨
  - **별빛 대장간**: 검은 별의 잔재를 처치하면 성운석 강화가 개방됨. 별의 균열 보스는 첫 승리와 재도전 승리마다 성운석 3개와 장비 조각 5개를 확정 지급하며, 보스 전용 장비도 동일 장비 없이 강화할 수 있음
  - 강화할 때 `동일 장비 1개` 또는 `성운석` 중 소비할 재료를 직접 선택함. 성운석은 +1에 1개, +2에 2개, …, +5에 5개와 기존 강화 골드를 소비함. 성운석은 전투 사용·판매가 불가능하며 저장·복원됨. 기존 클리어 저장은 별빛 강화가 열리며 재도전으로 재료를 획득할 수 있음
- **장비 분해·무기 합성·옵션 재련**: 시작 마을 공방에서 미착용 장비를 `장비 조각`으로 분해하고, 7개 무기 계열과 5개 등급을 지정해 새 무기를 확정 합성함
  - 분해량은 일반 1·고급 3·희귀 8·영웅 20·전설 50개이며 강화 보너스는 +1/+2/+3/+4/+5 순서로 3/7/12/18/25개가 추가됨. 장착 중이거나 잠금 보호된 장비는 분해 목록에 포함되지 않음
  - 웹 공방에서 등급·무기 계열·미강화·파티 직업 비호환 필터와 다중 선택을 지원하며, 선택 장비의 예상 조각 합계를 확인한 뒤 일괄 분해할 수 있음. 전설·강화·잠금 장비는 안전 일괄 분해에서 자동 제외됨
  - 희귀 이상 생성 장비는 옵션 재련 가능. 희귀 6조각+40G, 영웅 12조각+90G, 전설 25조각+180G를 사용하며 기존 옵션 하나를 고정하면 비용이 2배가 됨. 변경 전·후 능력치를 확인한 뒤 확정하며 강화 단계·장비 잠금·기본 능력치는 유지됨
  - 합성 비용은 일반 4개/15G, 고급 10개/35G, 희귀 24개/80G, 영웅 55개/180G, 전설 120개/400G이며 실패나 재료 손실 확률은 없음
  - 합성 전 예상 레벨·능력치 범위·무작위 부가 옵션 수·현재 파티의 장착 가능 직업을 미리 확인할 수 있음
  - 장비 조각은 저장·복원되고, 웹에서는 확인 후 자원·인벤토리가 달라진 요청과 중복 전송을 거부함
  - 상점의 장비 판매 목록과 공방의 분해 목록에 각각 판매 골드와 분해 조각을 함께 표시함. 강화 단계에 따른 조각 보너스를 반영하며 잠금·착용 장비는 대상에서 제외됨. 판매 전에는 포기하는 조각 수를 다시 확인함
- **특화 상점 시스템**: 시작 마을의 여행자 잡화점·바람칼 무기점·철벽 방어구점이 서로 다른 재고를 판매함. 약초꾼 세아를 구출하면 `세아의 약초점`이 추가로 열리고 HP 40·MP 10을 함께 회복하는 `달빛 영약`을 구매할 수 있음. 세아를 마을까지 호위하면 약초점 전 상품이 20% 할인됨. 각 상점에서 보유 중인 아이템/장비를 정가의 50%에 판매할 수 있음
- **저장/불러오기 (슬롯 3개)**: 탐험 중 메뉴에서 "게임 저장" 선택 시 슬롯 1~3 중 하나를 골라 `saves/slot{번호}.json`에 저장. 기존 슬롯은 확인 후 덮어쓰며, 임시 파일과 `.bak` 백업을 사용함. 저장 버전과 콘텐츠를 검사하여 손상되거나 호환되지 않는 저장은 안전하게 거부함. 파티 스탯, 골드, 장비, 인벤토리, 현재 위치, 보스 처치·대화 재생 여부, 스토리 flags, 상태이상, 잠긴 문 개방 상태까지 전부 저장됨
  - 슬롯 목록에서 파티 평균 레벨, 직업 구성, 한글 장소명, 골드, 누적 플레이 시간, 마지막 저장 시각을 한눈에 확인할 수 있음
  - 플레이 시간은 이전 저장까지의 누적 시간에 현재 실행 시간을 더해 기록함
  - 메타데이터가 없는 버전 1~6 저장도 불러올 수 있으며, 장소명과 저장 시각은 기존 정보에서 자동 보완함
- **보스 AI**: 보스/미니보스(`smart_ai=True`)는 상황을 판단해서 행동함 — 디버프는 가장 위협적인(공격력 높은) 상대에게, 공격은 가장 약해진(HP 낮은) 상대를 집중 공격. 일반 몬스터는 여전히 무작위로 행동해서 난이도 곡선이 자연스러움
  - 콘솔과 웹 전투에서 살아 있는 적의 다음 행동과 목표 성향을 미리 표시함. 반복 행동 순서와 현재 MP 부족에 따른 기본 공격 대체, 아직 발동하지 않은 체력 구간 전용기를 반영하되 예고 확인 자체는 행동 순서나 페이즈 상태를 변경하지 않음. 일반 몬스터는 `불규칙 행동`으로 표시함
  - 다크 나이트·탄광 드레이크·봉인된 마왕·탑의 수호자는 각자 반복되는 전용 행동 순서를 사용함
  - 동굴 골렘은 HP가 50% 이하가 되면 전투당 한 번 파티 전체를 공격하는 `암석 반격`을 사용함
  - 다크 나이트는 HP 50% 이하에서 `암흑 폭주`, 안개의 여왕은 HP 65%·30% 구간에서 `안개 장막`·`심연의 안개`, 봉인된 마왕은 HP 70%·35% 구간에서 `심연의 결계`·`최후의 심판`을 순서대로 발동함
  - 체력이 한 번에 크게 줄어 여러 구간을 통과해도 높은 단계부터 차례대로 발동하며, 각 전환 장면은 콘솔과 웹 전투 로그에 전용 메시지로 표시됨
  - 1차 자동 분석과 조정 후 재검증 결과를 반영해 보스 HP를 약 9%~27% 높이고, 힐러에게 공격력 +1과 무소모 공격 `빛의 화살`을 추가했으며, 소환술사의 주력 소환 위력을 약 9%~11% 조정함
- **일반 몬스터 랜덤 드랍**: 전투에서 이기면 각 몬스터마다 정해진 확률로 아이템을 떨어뜨림 (몬스터마다 서로 다른 드랍 목록/확률). 예: 슬라임은 20% 확률로 포션, 독거미는 25% 확률로 해독제 (자신이 주는 중독과 테마가 맞음)
- **중요 아이템 보호**: 열쇠처럼 진행에 필요한 아이템은 전투에서 사용할 수 없고 상점에도 판매할 수 없어 실수로 잃어버리지 않음
- **상태이상**: 중독(매턴 HP 피해)과 마비(턴 스킵)를 지원. 스킬에 `inflict_status`를 지정하면 일정 확률로 상태이상을 걸 수 있음. 해독제 같은 아이템으로 치료 가능. 매턴 시작 시 자동으로 피해 적용/지속시간 감소/만료 처리됨
  - 현재 예시: 독거미의 "독니"(중독), 다크 나이트의 "마비의 일격"(마비), "해독제"(중독 치료, 마을 상점 판매)
- **버프/디버프**: 공격력·방어력·속도를 일정 턴 동안 올리거나 내리는 효과. 상태이상과 같은 구조(`StatusEffect`)를 공유해서 지속시간이 지나면 자동으로 사라짐
  - 현재 예시: 전사의 "전투 함성"(자신의 공격력 강화), 마법사의 "약화의 저주"(적의 방어력 약화), 다크 나이트의 "위협의 포효"(파티원의 공격력 약화)
- **속성 마법**: 공격 스킬에 화/냉/뇌 속성을 지정할 수 있고, 대상의 약점 속성이면 1.5배, 저항 속성이면 0.5배 피해. 전투 화면에 "약점을 찔렀다!" / "효과가 별로인 듯하다..." 로 표시됨
  - 마법사는 파이라(화)/블리자라(냉)/선더라(뇌) 3속성을 모두 사용 가능
  - 몬스터 약점/저항 예시: 박쥐 무리(뇌 약점), 숲의 정령(화 약점, 식물 계열), 탄광 드레이크(냉 약점 + 화 저항, 불 드레이크라서)
- **전체공격(광역) 스킬**: `Skill.aoe=True`로 지정하면 살아있는 적(또는 회복/버프라면 파티원) 전체에게 한 번에 효과 적용. MP는 대상 수와 상관없이 한 번만 소모됨
  - 현재 예시: 소환술사의 "소환: 라무" (모든 적에게 번개 피해)
- **조건부 이동 (잠긴 문)**: 특정 아이템(열쇠)을 가지고 있어야 지나갈 수 있는 문. 열쇠가 없으면 선택지에 🔒 표시와 함께 필요한 아이템 이름이 보이고, 이동을 시도하면 막힘. 열쇠가 있으면 자동으로 소모하고 영구적으로 열림 (다음부터는 열쇠 없이 자유롭게 통행)
- **마을 여관**: 시작 마을에서 무료로 휴식하여 전투 불능을 포함한 파티 전원의 HP·MP를 최대치로 회복하고 중독·마비·버프·디버프와 방어 상태를 모두 해제함
- **도전의 탑 귀환**: 탑의 수호자를 쓰러뜨린 뒤 정상의 마법진을 이용해 시작 마을로 즉시 귀환할 수 있음
- **도전의 탑 반복 도전**: 최초 정복 후 마을에서 다음 단계를 개방할 수 있음. 단계마다 수호자의 체력·공격력·방어력·속도와 기본 보상이 상승하며, 2회차부터 추가 골드와 파티 성장 수준에 맞는 무작위 장비를 지급함. 최초 보상인 전설의 갑옷은 한 번만 획득함
  - 현재 예시: 폐광 깊은 곳에서 "녹슨 열쇠"를 주우면, 동굴의 잠긴 철문을 열고 "동굴 비밀 금고"(행운의 반지)에 들어갈 수 있음 — 서로 다른 던전을 오가며 탐험하도록 유도하는 장치

## 스토리 대화를 추가하는 방법 (dialogues.py + story.py)
```python
from story import DialogueNode, Dialogue

def my_event() -> Dialogue:
    def set_flag(flags):
        flags["found_key"] = True

    end = DialogueNode("end", ["...상자를 열자 열쇠가 들어있었다."], effect=set_flag)
    start = DialogueNode(
        "start",
        ["낡은 상자가 놓여 있다."],
        choices=[("상자를 연다", "end"), ("무시하고 지나간다", None)],
    )
    return Dialogue(nodes=[start, end], start_id="start")
```
그리고 `world.py`에서 원하는 `Location`에 `dialogue=my_event()`로 연결하면 됩니다.
나중에 다른 대화에서 `flags.get("found_key")`로 이 선택을 참조할 수 있습니다
(엔딩 대사가 갈리는 `dialogues.ending_dialogue()`가 좋은 예시입니다).

## 맵에 새 지역을 추가하는 방법 (world.py)
```python
new_place = Location(
    loc_id="cave2",                       # 고유 id
    name="어두운 동굴 2",
    description="...",
    exits={"더 안쪽으로": "cave2_deep"},   # 문구 -> 이동할 loc_id
    encounter_chance=0.5,                 # 이 장소로 "들어올 때" 전투가 발생할 확률
    encounter_pool=[lambda: [data.create_goblin()]],  # 뽑힐 수 있는 전투 구성들
    boss=lambda: [data.create_dark_knight()],  # 보스방이면 지정 (1회성, 자동 발동)
    is_ending=True,                       # 엔딩 지점이면 True
    shop_items=[data.POTION],             # 상점을 두고 싶다면 파는 아이템/장비 목록 지정
    shop_equipment=[data.IRON_SWORD],
    loot_item=data.POTION,                # 이 장소에 처음 들어왔을 때 1회성으로 얻는 아이템
    loot_equipment=data.MITHRIL_DAGGER,   # 1회성으로 얻는 장비 (boss가 있으면 처치 후에만 획득 가능)
)
```
그리고 `build_world()`의 `locations=[...]` 리스트와 다른 장소의 `exits`에 연결해주면 됩니다.
`shop_items`나 `shop_equipment` 중 하나라도 넣으면 그 장소의 메뉴에 "상점 이용하기"가 자동으로 나타납니다.

**갈림길/사이드 던전 만들기**: 한 장소의 `exits`에 두 개 이상의 목적지를 넣으면 자연스럽게 갈림길이 됩니다.
"동굴"과 "도전의 탑"이 이 패턴의 예시입니다 — 둘 다 메인 스토리(숲→폐허)와는 별개로 마을/숲 입구에서 갈라져서,
강력한 보스를 처치하면 메인 경로에서는 구할 수 없는 전용 장비를 주는 구조로 되어 있습니다.
탐험 메뉴의 "지도 보기"는 `GameMap.visited`에 기록된, 즉 플레이어가 실제로 가본 장소만 보여주므로
새 지역을 추가해도 스포일러 없이 자연스럽게 지도가 채워집니다.

**층으로 이어지는 던전(도전의 탑) 만드는 패턴**: 여러 장소를 사슬처럼 연결하고, 각 층의 `encounter_chance`와
`encounter_pool`을 점점 세게 만든 뒤, 마지막 장소에만 `boss`와 `loot_equipment`를 지정하면 됩니다.
```python
tower_floor_1 = Location(loc_id="tower_floor_1", name="탑 1층", ..., exits={"2층으로": "tower_floor_2", "마을로": "village"})
tower_floor_2 = Location(loc_id="tower_floor_2", name="탑 2층", ..., exits={"3층으로": "tower_floor_3", "1층으로": "tower_floor_1"})
# ... 이런 식으로 계속 이어가다가 마지막 층에 boss=lambda: [...], loot_equipment=... 를 지정
```

**메인 스토리에 반전/추가 보스전을 끼워넣는 패턴**: 기존 보스방의 `exits`가 바로 다음 장소(예: 엔딩)로 가지 않고
새로 만든 장소로 향하게 바꾼 뒤, 그 사이에 대화+장소를 몇 개 끼워넣으면 자연스럽게 스토리가 길어집니다.
```python
# 기존: ruins.exits = {"...": "ending"}
# 변경 후: ruins.exits = {"...": "새_장소"} 로 바꾸고, 새_장소 -> ... -> ending 순서로 연결
```
이 패턴을 쓸 때 대화의 선택지가 이후 다른 대화(특히 엔딩)에서 참조하는 `flags`를 여러 개 쌓아두면,
`ending_dialogue()`의 `text_fn`에서처럼 조합에 따라 결말이 여러 갈래로 갈리게 만들 수 있습니다
(현재 게임은 `promised_elder` + `embraced_power` 두 flag의 조합으로 엔딩이 4갈래).

## 새 상태이상을 추가하는 방법 (models.py + data.py)
1. `models.py`의 `STATUS_KINDS`에 종류 이름 추가 (예: `"sleep"`)
2. `Character.tick_status_effects()`에서 그 종류에 대한 매턴 효과가 필요하면 분기 추가 (중독처럼 매턴 피해를 주는 게 아니라면 생략 가능)
3. 마비처럼 "행동 자체를 막는" 효과라면 `Character.is_paralyzed()`와 비슷한 판정 메서드를 추가하고 `combat.py`의 턴 처리부에서 확인
4. `data.py`에서 스킬을 만들 때 `inflict_status`, `status_name`, `status_power`, `status_duration`, `status_chance`를 지정
```python
SLEEP_DUST = Skill(
    name="수면 가루", mp_cost=5, power=2, kind="attack",
    description="가루를 뿌려 상대를 잠재운다.",
    inflict_status="sleep", status_name="수면", status_duration=2, status_chance=0.6,
)
```
5. 치료 아이템이 필요하면 `Item(cures_status="sleep", ...)`으로 정의하고 `ITEMS_BY_NAME`에 등록

## 새 버프/디버프 스킬을 추가하는 방법 (data.py)
```python
HASTE = Skill(
    name="가속", mp_cost=4, power=0, kind="buff",
    description="스스로의 속도를 높인다.",
    buff_stat="speed", buff_amount=5, buff_duration=3, buff_name="속도 강화",
)
SLOW = Skill(
    name="둔화", mp_cost=4, power=0, kind="debuff",
    description="적의 속도를 낮춘다.",
    buff_stat="speed", buff_amount=4, buff_duration=3, buff_name="속도 약화",
)
```
`buff_stat`은 `"attack"`, `"defense"`, `"speed"` 중 하나여야 합니다. `kind="buff"`는 자동으로 자기 자신(또는 파티원 중 선택한 대상)에게,
`kind="debuff"`는 상대에게 적용됩니다. 지속시간이 끝나면 자동으로 사라지고 화면에 알려줍니다.
캐릭터의 실제 전투 스탯(`effective_attack` 등)은 항상 "기본 스탯 + 장비 보너스 + 버프/디버프 보정치"로 계산되며, 0 밑으로는 내려가지 않게 되어 있습니다.

## 전체공격(광역) 스킬을 만드는 방법 (data.py)
```python
BLIZZAGA = Skill(

    description="얼음 폭풍으로 모든 적에게 피해를 입힌다.",
)
```
`aoe=True`만 추가하면 됩니다. `kind`가 `"attack"`/`"debuff"`/`"steal"`이면 살아있는 적 전체, `"heal"`/`"buff"`면 파티원 전체에게 적용됩니다.
MP는 대상 수와 관계없이 스킬 1회 사용분만 소모됩니다 (`Character.use_skill_on_targets` 참고).

# 강화 미리보기

마을 대장간에서 동일 장비 강화와 성운석 강화의 능력치 변화를 소비 전에 확인할 수 있습니다.
웹 장비 목록·확인창과 콘솔 확인 단계에 강화 전후 수치가 표시됩니다.
미리보기는 실제 강화와 같은 계산을 사용하며 골드·재료·장비를 변경하지 않습니다.

## 강화 거래 보호 및 착용 정책

- 웹 강화는 확인 당시의 장비 순서·수치·골드·재료에 묶인 확인 토큰을 요구합니다. 성공 후 토큰은 폐기되며 오래된 화면의 요청은 자원을 소비하지 않고 재확인을 안내합니다.
- 동일 장비 재료는 미강화(+0) 장비만 사용합니다. 강화된 장비는 자동 소모하지 않습니다.
- 장비 관리와 상점의 장비 수치는 저장된 설명문 대신 실제 능력치 필드에서 생성합니다. 구버전 저장에도 적용됩니다.
- 착용·해제는 현재 HP·MP를 회복하거나 부활시키지 않습니다. 최대치가 낮아지면 현재량을 새 최대치까지 제한합니다.
- 성운석은 균열 승리당 3개이며, 첫 보물은 한 번만 지급합니다. 강화 비용은 다음 강화 단계만큼입니다.
- 웹 API는 객체 형태의 JSON 요청만 처리하며, 강화 확인 토큰의 재사용·오래된 요청은 자원을 소비하지 않고 400 오류로 거절합니다.
